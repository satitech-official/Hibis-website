## About the Project

HIBIS is a premium hotel and resort website focused on modern luxury hospitality. The experience combines cinematic imagery, elegant editorial layouts, interactive motion, immersive room discovery and strong booking calls-to-action.

The project includes dedicated experiences for HIBIS properties, rooms, dining, wellness, offers, gallery and hotel information while keeping the interface responsive across desktop, tablet and mobile devices.

## Highlights

- Cinematic full-screen hero experience
- Premium animated loader and smooth transitions
- Interactive cursor and magnetic CTA interactions
- 3D depth, parallax and scroll-based storytelling
- Interactive room discovery and comparison
- Dedicated room detail pages
- Immersive gallery with filtering and lightbox experience
- Dining, wellness, offers and property sections
- Responsive navigation and mobile menu
- Reduced-motion accessibility support
- SEO metadata, structured data, sitemap and robots configuration
- Static-export deployment optimized for GitHub Pages

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- React Three Fiber / Drei
- Lucide React

## Local Development

```bash
git clone https://github.com/satitech-official/Hibis-website.git
cd Hibis-website
pnpm install
pnpm dev
```

Production checks:

```bash
pnpm lint
pnpm typecheck
pnpm build
```

## Deployment

The repository contains a GitHub Actions workflow that automatically performs linting, TypeScript validation, a production static export and deployment to GitHub Pages whenever changes are pushed to `main`.
