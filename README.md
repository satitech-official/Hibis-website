# HIBIS — Premium 3D Hotel Website

A premium, cinematic and immersive hotel website designed for **HIBIS**, focused on delivering a modern luxury hospitality experience through interactive UI, 3D depth, smooth animations, high-quality visuals and elegant editorial design.

The website combines **luxury hospitality aesthetics with modern interactive web experiences** to create a memorable digital journey for visitors.

The visual direction focuses on:

* Architecture
* Hospitality

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project

```bash
cd hibis-premium-3d-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local development URL shown in your terminal.

---

## 🏗️ Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
